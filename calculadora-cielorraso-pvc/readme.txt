Calculadora de materiales para cielorrasos de PVC, 100 % configurable desde el panel: materiales, fórmulas, desperdicios, cotización, leads y exportación.

== Description ==

* Shortcode [calculadora_cielorraso], bloque Gutenberg y widget de Elementor.
* Materiales ilimitados con nombre, descripción, unidad, largo, ancho, rendimiento, precio, % de pérdida, mínimos, redondeos, factor de corrección, variantes de largo y estado.
* Fórmulas editables con un motor seguro (sin eval) y reglas de cálculo intermedias.
* Sentido de colocación "más económico" y elección automática del largo de lámina.
* Mostrar u ocultar precios (cotización automática).
* Captura de leads antes de los resultados, con exportación CSV / Excel.
* Exportación del presupuesto a PDF y Excel, e impresión.
* Compatible con Elementor, Gutenberg, Astra, GeneratePress y Hello Elementor.

== Installation ==

1. Subir el ZIP desde Plugins > Añadir nuevo > Subir plugin y activarlo.
2. Configurar en "Cálculos de Cielorraso > Ajustes".
3. Insertar [calculadora_cielorraso] o el bloque "Calculadora de cielorraso PVC".
